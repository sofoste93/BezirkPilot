# Android releases

All APKs require Android 8.0 (API 26) or newer. Every public version is signed with
the same BezirkPilot release certificate, allowing Android to update an earlier
public installation without removing application data.

| Version | Focus | APK SHA-256 |
| --- | --- | --- |
| 0.1.0 | Static login and high-contrast 1990s-inspired district cockpit | `aa6d37eafe60f21aea239fefe4ec11970849a310d4a8fd41bf9803fbeefeabe0` |

Use the latest release for normal installations. Historical versions remain
available for transparency, testing and archival purposes.
